# Specs

Cada funcionalidad tiene una carpeta `NNN-nombre/` con:

- `spec.md` — qué hace, para quién, reglas y criterios de aceptación.
- `plan.md` — cómo se implementa (opcional en specs pequeños).
- `tasks.md` — tareas pequeñas y verificables (opcional).

Todo spec respeta `docs/constitucion.md`.
